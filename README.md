## my-food-app

- This is a MERN Stack web application
- In this application, user can do the following activities
    - Signup user
    - Signin user
    - Signout
    - View profile details
    - Edit user details
    - Browse restaurants
    - Results for the selected collections
    - View Restaurant and items details
    - Add to cart
    - View Checkout amount
    - Remove from cart
    - JWT Authentication added
